# آزمون مرورگر واقعی نسخه مسابقه | ۲۳ اکتبر ۲۰۲۶

## هدف
افزودن آزمون خودکار Chromium به گیت نهایی به‌جای تکیه صرف بر pytest و Vitest. این آزمون در دیتابیس PostgreSQL موقت با **داده کاملاً ساختگی** اجرا می‌شود. هیچ CSV/ZIP مسابقه و هیچ API key وارد مخزن یا artifacts نمی‌شود.

## پوشش
- زبان `fa` و `dir=rtl`، نبود سرریز افقی در عرض‌های ۳۲۰، ۳۹۰ و ۱۴۴۰ پیکسل.
- جست‌وجوی محصول، نمایش نتایج و کارت‌ها.
- انتخاب دستی محدوده تهران بدون مجوز GPS.
- بازشدن فهرست دو فروشنده و نقشه اختیاری.
- استعلام ناموفق شبیه‌سازی‌شده، مراجعه به فروشنده دوم و تولید برنامه مراجعه.
- ذخیره اسکرین‌شات‌های اجرای CI برای بازبینی بصری.

## اجرای CI
گیت `browser-journey` در `.github/workflows/ci.yml` با ایجاد PR آماده بازبینی یا `workflow_dispatch` اجرا می‌شود. قدم‌ها: نصب Playwright/Chromium، migration، seed ساختگی، اجرای Django و Vite و آزمون `scripts/browser_journey.py`.

## حدود
این تست جای بررسی واقعی Chrome/Safari موبایل، آزمون ۲۰ edge case، ۱۲ مسیر با دیتاست حقیقی، شرایط شبکه موبایل، API LLM و دیپلوی عمومی را نمی‌گیرد. شکست بارگذاری نقشه بیرونی نباید تجربه فهرست فروشگاه‌ها را از کار بیندازد.
