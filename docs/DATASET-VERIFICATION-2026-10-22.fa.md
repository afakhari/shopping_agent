## سازگاری با کد موجود
- نام سه CSV و هدرهای آن‌ها با `backend/apps/catalog/management/commands/import_dataset.py` تطابق دارند.
- parser واردکننده برای مقدار متنی `null`، JSON فشرده، Decimal قیمت، timestamp و مختصات طراحی شده است.
- تست خود واردکننده Django روی PostgreSQL و **واردکردن واقعی داده** در این ممیزی انجام نشده است. این‌ها باید جداگانه روی محیط دارای سرویس DB اجرا شوند.

## گام بعدی اجرای واقعی بدون مصرف GitHub Actions

۱. فایل ZIP را در محیط اجرایی خصوصی نگهداری کنید؛ در مخزن عمومی Git یا frontend قرار ندهید.
۲. PostgreSQL و Django backend را با تنظیمات محیطی امن اجرا کنید.
۳. از پوشه `backend/`، پیش از تغییر داده تست dry-run بزنید:

```bash
python manage.py import_dataset --archive /secure/path/starcoach-dataset-v16-cap300-csv.zip --dry-run
```

۴. پس از بررسی خروجی، import واقعی را با حذف `--dry-run` اجرا کنید و شمارش رکوردهای دیتابیس، دسترسی API و سرعت جست‌وجو را بسنجید. اجرای دوباره باید idempotent باشد.
۵. با fixtures واقعی دارای قیمت NULL، اعتبار حضوری و آدرس پاساژ مسیر Golden Path را ارزیابی کنید.

**تفکیک وضعیت:** ممیزی فایل خام انجام شده است؛ import واقعی PostgreSQL، smoke test API، نقشه و استقرار عمومی هنوز تأیید نشده‌اند.
