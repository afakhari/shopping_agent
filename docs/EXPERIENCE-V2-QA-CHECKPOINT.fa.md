# Experience v2: نقطه کنترل کیفیت متمرکز

این PR فقط ثبت نقطه کنترل کیفیت برای همان کد منتشرشده در main است؛ هیچ تغییر runtime نسبت به main ندارد و به‌جای اجرای CI برای چند commit طراحی، تنها یک بار کیفیت کل لایه UX جدید را بررسی می‌کند.

## پوشش
- React/TypeScript: ساخت فضای کار بزرگ‌تر، راهنمای چهار مرحله خرید، خوشامدگویی فارسی، کارت‌های تصمیم‌محور و حفظ رفتارهای SSE، جستجو، مقایسه و استعلام
- CSS: design tokens، RTL، کنتراست رنگ، focus-visible، reduced-motion، forced-colors، viewport موبایل ۳۲۰ تا ۱۹۲۰
- آزمون استاتیک جدید: پنج contract test در frontend/src/app/experience-v2.test.ts
- مستندات تصمیم معماری: docs/EXPERIENCE-V2-DESIGN-SYSTEM.fa.md

## محدودیت ادعای تأیید
این CI فقط سلامت کد، TypeScript، build، تست‌های موجود و lint را تأیید می‌کند؛ کیفیت پیکسلی، حرکت با کیبورد در مرورگر واقعی، screenshot موبایل، و رفتار روی دستگاه‌های مختلف پس از Pull و Build محلی باید جداگانه بررسی شوند. تغییر در شبیه‌ساز فروشگاه یا دیتاست اعمال نشده است.
