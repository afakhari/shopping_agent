# اجرای آزمون یکپارچه پس از اصلاحات مهم (Windows)

این اسکریپت CI در GitHub Actions مصرف نمی‌کند و دیتاست مسابقه را مجدد import نمی‌کند. تست‌های Django دیتابیس جداگانه خودشان را می‌سازند و دیتابیس واقعی پروژه حذف نمی‌شود.

پیش‌نیاز: Docker Desktop روشن، کپی محلی repo و ZIP از قبل واردشده.

```powershell
cd "$HOME\Downloads\shopping_agent"
git pull --ff-only origin main
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-golden-path.ps1
```

گیت محلی این موارد را بررسی می‌کند:
- rebuild آخرین frontend/backend و اجرای migrations در Docker
- `python manage.py check` و تطابق migrationها
- شمارش کل رکوردها در PostgreSQL واقعی (225903/6476/331506)
- تست‌های Django مأموریت، ایجنت، جست‌وجو، سلامت و کاتالوگ روی دیتابیس تست مستقل
- درخواست HTTP واقعی از داخل شبکه Docker از طریق Nginx: جست‌وجو، ایجاد مأموریت، SSE، اعمال شروط سخت و حداقل یک استعلام شبیه‌سازی‌شده

در صورت محدودیت زمان، `-SkipBackendTests` فقط برای تست سریع وجود دارد ولی جایگزین تست کامل نهایی نیست.

## تغییر مهم امنیت نشست
مأموریت‌های جدید به نشست ایجادکننده در همان مرورگر متصل‌اند. شناسه مأموریت به‌تنهایی مجوز دسترسی نیست. در مرورگری که قبل از این اصلاح مأموریت ساخته است، گفتگوی قبلی ممکن است دیگر قابل بازیابی نباشد؛ با «گفتگوی تازه» مأموریت جدید بسازید. پاک‌کردن دیتاست یا docker volume لازم نیست.

## حد واقعی تأیید
اجرای موفق فقط مسیر محلی با سناریوی شبیه‌سازی را تأیید می‌کند؛ امنیت عمومی، نقشه کامل، عملکرد مدل زبانی اختیاری، ۲۰ حالت لبه‌ای و accessibility در release gate مستقل بررسی می‌شود. اگر دستور خطا داد، خروجی پیام خطا را ارسال کنید، نه فایل `.env` و اسرار محلی.
