# انتخاب محدوده دستی و پیش‌نمایش نقشه | ۲۳ اکتبر ۲۰۲۶

## آنچه افزوده شد
- در کنار GPS، انتخاب دستی چند محدوده تهران بدون نیاز به اجازه موقعیت مرورگر.
- مختصات نمونه از **میانه مختصات فروشگاه‌هایی** گرفته شده‌اند که متن آدرس/موقعیتشان شامل نام محدوده بوده است. این مختصات مرکز دقیق محله یا موقعیت شخص نیستند.
- نمایش اختیاری و lazy یک نقشه OpenStreetMap برای فروشگاه انتخاب‌شده، همراه با لینک خروجی و فهرست فروشندگان.
- اگر نقشه بیرونی بارگذاری نشود، آدرس، فهرست و لینک قبلی باقی می‌مانند.
- هیچ کلید نقشه یا توکن محرمانه وارد فرانت‌اند نشده است.

## محدودیت
- iframe نقشه فقط **یک فروشگاه انتخاب‌شده** را نمایش می‌دهد؛ هنوز نقشه چندپینی همگام با لیست و خوشه‌بندی کامل ساخته نشده است.
- API زمان سفر/ETA و مسیریابی واقعی نیازمند انتخاب سرویس و اعتبارسنجی سهمیه و کلید است.
- استفاده از iframe منجر به درخواست به OpenStreetMap فقط پس از بازکردن پیش‌نمایش توسط کاربر می‌شود.

## کیفیت
اجرای unit تست `shop-map.test.ts`، بررسی ریسپانسیو عرض ۳۲۰/۳۹۰ و آزمون با geolocation denied قبل از پذیرش production الزامی است.
