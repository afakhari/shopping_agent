# تصمیم محصولی: نقشه بدون خرید اعتبار نشان | ۲۳ اکتبر ۲۰۲۶

**تصمیم مالک:** «اعتبار نشان ندارم و نمی‌خواهم بخرم.» بنابراین **هزینه API نشان باید صفر بماند**. ساخت کلید قبلی الزام استفاده از آن نیست؛ کلید خصوصی نباید در مخزن، گفتگو یا frontend قرار گیرد.

## رفتار اجرایی نسخه رایگان

- فهرست فروشندگان همان محصول و انتخاب ساختاریافته آفر از PostgreSQL حفظ می‌شود. اگر فقط **یک** فروشنده باشد، نمایش اختیاری موقعیت او نیز در دسترس است.
- دکمه «نمایش نقشه OpenStreetMap» فقط پس از انتخاب فروشنده و کلیک مستقیم کاربر iframe را می‌سازد. انتخاب‌نکردن آن، تماس اجباری با سرویس نقشه ایجاد نمی‌کند.
- لینک‌های رسمی **بدون کلید** به نقطه ثبت‌شده و مسیر خودرو در وب/اپ نشان، فقط با کلیک کاربر باز می‌شوند و از کلید REST پروژه مصرف نمی‌کنند. ممکن است سرویس خارجی هزینه یا شرایط مخصوص خود داشته باشد، اما از API پولی پروژه درخواست ارسال نمی‌شود.
- رابط پیش‌فرض هیچ کارت «سرویس نشان غیرفعال است»، «خرید/فعال‌سازی API» یا دکمه محاسبه پولی را نمایش نمی‌دهد. کنترل‌های پولی فعلی فقط با opt-in صریح `VITE_ENABLE_PAID_NESHAN_ROUTES=1` در build قابل مشاهده‌اند و backend همچنان جداگانه disabled می‌ماند.
- دو کلید backend `NESHAN_ROUTING_ENABLED=0` و `NESHAN_DIRECTION_ENABLED=0` و دو سقف `NESHAN_ROUTING_MAX_CALLS_PER_MISSION=0` و `NESHAN_ROUTING_DAILY_MAX_CALLS=0` باقی بمانند. نیازی به افزودن هیچ اعتبار مالی یا ثبت key به runtime پروژه نیست.
- فاصلهٔ مستقیم فقط هنگامی که مبدأ تعریف شده با همین نام نمایش داده می‌شود، **نه ETA یا فاصله خیابانی**. همه قیمت‌ها ثبت‌شده، موجودی حضوری تأییدنشده و نام بسیاری از فروشگاه‌ها آزمایشی/ساختگی‌اند.
- نبود مختصات تهران یا عدم دسترسی نقشه، فهرست/آدرس متنی و انتخاب فروشنده را از کار نمی‌اندازد؛ نمایش نقطه بیرون تهران یا geocoding نام ساختگی ممنوع است.

## محدودیت حیاتی OpenStreetMap

**داده جغرافیایی OSM رایگان است اما tile serverهای عمومی OSMF سرویس تجاری نامحدود و تضمین‌شده نیستند.** استفاده کم‌ترافیک از iframe سایت OSM برای دمو و پیش‌نمایش انتخابی در چارچوب مقررات سرویس ممکن است؛ پیش از استفاده پرترافیک یا production باید نیاز به tile provider سازگار، bandwidth و SLA جدا ارزیابی شود. از iframe/tiles برای bulk download، prefetch یا بنچمارک load استفاده نکنید. Attribution و copyright باید قابل مشاهده باشند. هرگونه استفاده مستقیم از `tile.openstreetmap.org` تابع سیاست URL، Referer، cache و شناسایی برنامه است. منبع رسمی: https://operations.osmfoundation.org/policies/tiles/

نقشه فعلی **نمایش تک‌نقطه‌ای است، نه نقشه چندپین تعاملی یا موتور زمان سفر**. اگر بعداً به نقشه چندپین نیاز شد، از Leaflet یا MapLibre به‌عنوان کتابخانه متن‌باز و **یک منبع تایل مجاز و مناسب حجم کار** استفاده می‌شود. هیچ provider نامحدودِ رایگان یا ETA واقعی بدون هزینه تضمین نشده است.

## معیار پذیرش و اجرای CI

- UI واحد: بدون `VITE_ENABLE_PAID_NESHAN_ROUTES=1` اصلاً بخش `mission-neshan-routing` ظاهر نشود و GET/POST route-estimates به‌سبب بازشدن بخش مکان ارسال نشود.
- یک فروشنده: کارت «موقعیت فروشنده» و کنترل نمایش نقشه موجود باشد.
- چند فروشنده: فهرست و انتخاب آفر دوطرفه همان نتیجه جاری و fallback حفظ شود.
- کاربر بدون مبدأ: فقط نقطه ممکن است باز شود؛ لینک مسیریابی از مبدأ ساختگی نمایش داده نشود.
- هیچ تستی به Neshan پولی یا tileهای OSM درخواست شبکه ارسال نکند؛ Chromium با fixture و بدون بازکردن لینک خارجی اجرا شود.
- یک اجرای جامع CI پس از تثبیت PR، نه اجرای مکرر بر هر کامیت.

## کارهای باقیمانده مرتبط با مسابقه

آزمون UX انسانی/دستگاه واقعی، ارزیابی مکالمات و gold retrieval، HTTPS عمومی، کنترل نرخ استفاده از tile در محیط نهایی و اعتبار داده فروشگاه‌ها هنوز نیازمند شواهد مستقل‌اند. داشتن کلید API نشان و خرید اعتبار **جزء پیش‌شرط این نسخه نیست**.
