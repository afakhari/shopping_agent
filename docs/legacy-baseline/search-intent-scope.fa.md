# دامنه‌گذاری قصد جست‌وجو (Search Intent Scope)

## مسئله

در دیتاست، عنوان «فشارسنج» هم برای دستگاه پزشکی و هم برای ابزار صنعتی/محیطی به کار رفته است. ممیزی `products.csv` نشان داد:

- ۳۴۶ محصول در دسته `فشارسنج پزشکی` هستند.
- ۳۸ محصول در دسته `بارومتر و فشارسنج محیطی` هستند.
- ۹ محصول در دسته `گیج فشار و مانومتر` هستند.
- دسته‌های مجاور دیگری مانند `درجه باد`، `ترانسمیتر فشار` و `دماسنج و رطوبت سنج` نیز وجود دارند.

بنابراین تطبیق لفظی صرف می‌تواند ابزار صنعتی ارزان‌تری را بالاتر از محصولی قرار دهد که کاربر عادی از «فشارسنج» انتظار دارد.

## رفتار فعلی پیاده‌سازی‌شده

- عبارت عمومی مانند `فشارسنج` یا `فشارسنج ارزان` به‌صورت پیش‌فرض به دسته پزشکی محدود می‌شود.
- پاسخ API در `intent_hint` توضیح می‌دهد که این پیش‌فرض اعمال شده و گزینه جایگزین `فشارسنج صنعتی` را پیشنهاد می‌کند.
- عبارت صریح مانند `فشارسنج صنعتی` یا `فشارسنج محیطی` به دسته‌های صنعتی/محیطی دامنه‌گذاری می‌شود.
- عبارت پزشکی صریح مانند `فشارسنج دیجیتالی` به دسته پزشکی دامنه‌گذاری می‌شود.
- جست‌وجوی دارای نشانه اختصاصی/ناشناخته (برای نمونه نام برند یا مدل `فشارسنج ناتالی ۱۰ بار سایز ۵ سانتی`) به‌صورت خودکار محدود نمی‌شود تا تطبیق دقیق حفظ شود.
- دامنه‌گذاری فقط مجموعه محصولات کاندیدا را محدود می‌کند؛ شروط قطعی آفر واجد شرایط، سقف بودجه، خرید اعتباری و محدوده مکانی همچنان در بک‌اند اعمال می‌شوند.

## قرارداد API

فیلد اختیاری/nullable `intent_hint` در پاسخ جست‌وجوی کاتالوگ:

```json
{
  "intent_hint": {
    "label": "فشارسنج پزشکی",
    "message": "برای عبارت عمومی ...",
    "alternative_label": "دیدن فشارسنج‌های صنعتی و محیطی",
    "alternative_query": "فشارسنج صنعتی"
  }
}
```

وقتی پیش‌فرض حوزه‌ای اعمال نشده باشد، `intent_hint` برابر `null` است. UI فقط در حالت پیش‌فرض‌گذاری بنر را نمایش می‌دهد و با کلیک روی گزینه جایگزین، عبارت جست‌وجو را تغییر می‌دهد.

## محدودیت و نگهداری

این یک قانون دامنه‌ای کوچک و قابل توضیح است، نه طبقه‌بند عمومی معنایی. واژه‌نامه را براساس مشاهده خطاهای واقعی گسترش دهید و برای هر قاعده تست مثبت، تست منفی و نمونه جست‌وجوی دقیق داشته باشید. از تعمیم این الگو به دسته‌های دیگر بدون بررسی فراوانی و هم‌پوشانی واقعی دسته‌ها خودداری کنید.
